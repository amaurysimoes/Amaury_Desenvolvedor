# Recriar node_modules em outra máquina

`node_modules` não vai para o GitHub (está no `.gitignore`). Ao baixar o projeto:

1. Instalar o Node.js 18 ou superior (https://nodejs.org). Conferir:
   ```bash
   node -v
   npm -v
   ```
2. Baixar o projeto e entrar na pasta:
   ```bash
   git clone https://github.com/amaurysimoes/Amaury_Desenvolvedor.git
   cd Amaury_Desenvolvedor
   ```
3. Recriar as dependências:
   ```bash
   npm install
   ```
4. Rodar:
   ```bash
   npm start        # desenvolvimento, http://localhost:5173
   npm run build    # gera dist/
   ```

## Se der erro

Apagar e instalar de novo:

```powershell
Remove-Item -Recurse -Force node_modules, package-lock.json
npm install
```

```bash
rm -rf node_modules package-lock.json
npm install
```
